### 3-确认缴费

确认缴费分为 **2 个必选步骤 + 1 个可选步骤**：

```
3A: 预结算 → 生成草稿，锁定收费项
3B: (可选) 银联被扫支付 → 仅 SCAN_PAY 时触发
3C: 正式结算 → 落账收费
```

---

### 4C-确认打印（审计落库）

#### 功能简述

请求方法:`POST`

接口：``/charging/charge/confirm-print`

功能：打印完成（成功或失败）后审计落库，记录打印操作日志。

#### 领域模型定义

##### 请求DTO:`ConfirmPrintRequestDTO`

| 字段              | Java 类型             | TS 类型                  | 可空 | 来源            | 说明                     |
| ----------------- | --------------------- | ------------------------ | ---- | --------------- | ------------------------ |
| `traceId`         | `String`              | `string`                 | ❌    | 4B 返回         | 打印追踪 ID              |
| `busNo`           | `String`              | `string`                 | ❌    | 4B 返回         | 模板业务号               |
| `scenarioCode`    | `String`              | `string`                 | ✅    | 固定值          | 场景码                   |
| `templateVersion` | `Integer`             | `number`                 | ✅    | 4B 返回         | 模板版本                 |
| `status`          | `String`              | `'SUCCESS' \| 'FAILED'`  | ❌    | hiprint 结果    | 打印结果                 |
| `printData`       | `Map<String, Object>` | `Record<string, unknown>` | ✅    | 4A 出参 + mapper | 实际打印的业务数据       |
| `bizRef`          | `Map<String, Object>` | `Record<string, unknown>` | ✅    | 调用方传入      | 业务锚点                 |
| `printer`         | `String`              | `string`                 | ✅    | 用户选择        | 打印机名称               |
| `copies`          | `Integer`             | `number`                 | ✅    | 配置            | 打印份数                 |
| `clientType`      | `String`              | `string`                 | ✅    | 常量            | 客户端类型               |
| `errorCode`       | `String`              | `string`                 | ✅    | hiprint 错误    | 失败时的错误码           |
| `errorMessage`    | `String`              | `string`                 | ✅    | hiprint 错误    | 失败时的错误信息         |
