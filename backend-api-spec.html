1 总体架构与通用规范

通用响应格式 JsonVO<T>

所有接口统一返回 JsonVO<T> 结构，前端 HttpClient 响应拦截器自动解包 data 字段：

// 后端统一响应体
{
  "code": 200,
  "message": "操作成功",
  "data": T // 泛型数据载体
}
字段类型说明
codenumber状态码，200=成功，401=未授权，403=禁止访问，500=服务器错误
messagestring提示信息，前端可直接展示给用户
dataT?业务数据，类型由具体接口决定
分页查询统一格式

请求参数（继承 PageQuery）

interface PageQuery {
  "pageIndex": number,  // 页码，从1开始
  "pageSize": number   // 每页条数，默认10
}

响应数据（PageDTO<T>）

interface PageDTO<T> {
  "content": T[],      // 当前页数据列表
  "totalElements": number, // 总记录数
  "totalPages": number,   // 总页数
  "pageIndex": number,    // 当前页码
  "pageSize": number     // 每页条数
}
参考系统使用 records + total 字段名。前端 Mock 当前使用 rows + total。后端统一采用 content + totalElements（Spring Data Page 标准格式），前端 adapter 层负责字段映射。
请求方法与 Content-Type
操作HTTP 方法Content-Type说明
分页查询POSTapplication/json查询条件复杂，统一用 POST body 传递
获取详情POSTapplication/json参考系统统一用 POST，body 传 { id: "xxx" }
新增POSTapplication/json请求体为 DTO 对象
修改PUTapplication/json请求体为 DTO 对象，URL 带 /{id}
删除DELETEapplication/jsonURL 带 /{id}
启用/停用POSTapplication/jsonbody 传 { id, enabled }
表单初始化POSTapplication/json获取下拉选项等元数据
参考系统（Java/Spring 后端）所有接口均使用 POST 方法。本规范对 CRUD 标准操作推荐使用 RESTful 方法（PUT/DELETE），同时兼容 POST 方式。
字段命名约定
场景命名风格示例
后端 Java 字段camelCasecategoryCode, manufacturerText
字典翻译字段原名_dictTextcategoryCode_dictText, doseFormCode_dictText
状态枚举UPPER_SNAKEACTIVE, INACTIVE, DRAFT
布尔标志xxxFlagactiveFlag, rxFlag, basicFlag
拼音/五笔码xxxStrpyStr, wbStr, merchandisePyStr
Vite 代理配置（开发环境）
// vite.config.ts 中的代理规则
"/api"     → "https://apifoxmock.com/m1/5579661-5257590-default"  // 业务接口（Mock）
"/captcha" → "http://localhost:10010"  // 验证码服务
"/ai"      → "http://localhost:10250"  // AI 智能助手服务
联调阶段需将 /api 代理目标修改为后端网关地址。环境变量 VITE_API_URL=/api（开发）或网关 URL（生产）。

17 后端实现指引

前端 API 层替换流程

前端采用关注点分离设计，每个模块的 index.ts 是唯一入口点。后端接口就绪后，只需修改 index.ts 内部实现，页面组件无需任何改动。

替换前（Mock 实现）

// src/apis/basicdata/frequency/index.ts
import { mockListFrequency } from './mock'
export const listFrequency = (query) => mockListFrequency(query)

替换后（真实接口）

// src/apis/basicdata/frequency/index.ts
import { useHttp } from '@/plugins/http'
const baseUrl = '/api/frequency'

export const listFrequency = async (query) => {
  const http = useHttp()
  const res = await http.post(baseUrl + '/pageFrequency', query)
  return res?.data
}
