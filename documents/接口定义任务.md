# 三个接口定义

> 参考项目 nginx 代理规则：前端 `/api/xxx` → 后端 `/api/app/xxx`

## 1. 入库单删除

```
POST /api/app/inventory/{module}/stock-in/{busNo}/delete
```

参数：
- module：warehouse（药库）、pharmacy（药房）
- busNo：单据号
- reason：删除原因（选填）

返回示例：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "busNo": "SI202607190001",
    "deletedLines": 3,
    "unlockedLocks": 3
  }
}
```

## 2. 盘点单删除

```
POST /api/app/inventory/{module}/stocktake/{busNo}/delete
```

参数：
- module：warehouse、pharmacy、department（科室）
- busNo：单据号
- reason：删除原因（选填）

返回同上。

## 3. 门诊批量发药

```
POST /api/app/outpatientPharmacyDispense/batchDispense
```

请求体：
```json
{
  "dispenseIds": ["322663105157926912"],
  "preparerId": "320000000000000001",
  "locationId": "320000000000000100",
  "lotSelections": [
    { "dispenseId": "322663105157926912", "lotNumber": "20260715-001" }
  ],
  "traceCodes": [
    { "dispenseId": "322663105157926912", "traceNo": "81234567890123456789" }
  ]
}
```

返回示例：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "totalCount": 2,
    "successCount": 2,
    "failCount": 0,
    "errors": []
  }
}
```
