# 盘点单新增保存接口文档

## 1. 业务范围

本接口文档对应本人负责的三个需求：

| 序号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 新增单据 | 创建盘点单草稿默认值，不生成正式单号 |
| 2 | 保存单据 | 保存盘点单；`busNo` 为空表示新增保存，不为空表示编辑保存 |
| 3 | 保存并提交审批 | 保存盘点单后提交审批，单据进入审批中状态 |

## 3. 领域模型

### 3.1 Query

`StocktakeDocumentQuery`

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `busNo` | `String` | 否 | `PD202607230001` | 盘点单业务单号 |
| `purposeLocationId` | `String` | 否 | `1001` | 盘点库房/药房位置ID |
| `statusEnum` | `String` | 否 | `PENDING_APPROVAL` | 单据状态 |
| `applyStartDate` | `String` | 否 | `2026-07-01` | 申请开始日期 |
| `applyEndDate` | `String` | 否 | `2026-07-31` | 申请结束日期 |
| `keyword` | `String` | 否 | `阿莫西林` | 关键字 |

### 3.2 DTO

`StocktakeSaveDTO`

| 字段 | 类型 | 必填 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `busNo` | `String` | 否 | 空 | `PD202607230001` | 新增保存为空，编辑保存传已有单号 |
| `purposeLocationId` | `String` | 是 | 无 | `1001` | 盘点库房/药房位置ID |
| `practitionerId` | `String` | 是 | 无 | `2001` | 经手人ID |
| `categoryEnum` | `String` | 否 | `STOCK_SUPPLY` | `STOCK_SUPPLY` | 供应类别 |
| `remark` | `String` | 否 | 空 | `期末库存盘点` | 单据备注 |
| `lines` | `List<StocktakeLineDTO>` | 是 | 无 | 见下表 | 盘点明细 |

`StocktakeLineDTO`

| 字段 | 类型 | 必填 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `itemTable` | `String` | 是 | 无 | `med_medication_definition` | 物品来源表 |
| `itemId` | `String` | 是 | 无 | `3001` | 药品/耗材定义ID |
| `unitCode` | `String` | 是 | 无 | `tablet` | 计量单位编码 |
| `actualQuantity` | `BigDecimal` | 是 | 无 | `95` | 实盘数量，不能为负 |
| `profitLossQuantity` | `BigDecimal` | 是 | `0` | `-5` | 盈亏数量，盘盈为正，盘亏为负 |
| `actualAmount` | `BigDecimal` | 否 | 空 | `190.00` | 实盘金额 |
| `profitLossAmount` | `BigDecimal` | 否 | 空 | `-10.00` | 盈亏金额 |
| `inventoryItemId` | `String` | 否 | 空 | `4001` | 库存项ID |
| `lotNumber` | `String` | 否 | 空 | `BATCH-20260723` | 批号 |
| `price` | `BigDecimal` | 否 | 空 | `2.00` | 单价 |
| `remark` | `String` | 否 | 空 | `期末盘点` | 行备注 |

### 3.3 VO

| VO | 用途 |
| --- | --- |
| `StocktakeDraftVO` | 新增草稿默认值 |
| `StocktakeSaveResultVO` | 保存单据结果 |
| `StocktakeSubmitResultVO` | 保存并提交审批结果 |

## 4. 接口定义

### 4.1 新增单据

| 项 | 内容 |
| --- | --- |
| 接口名称 | 新增单据 |
| 请求方式 | `POST` |
| 请求路径 | `/api/j7/stocktake/draft` |
| 请求参数 | 无 |
| 返回对象 | `JsonVO<StocktakeDraftVO>` |

响应示例：

```json
{
  "code": 10000,
  "message": "成功",
  "data": {
    "draftId": "draft-202607230001",
    "statusEnum": "DRAFT",
    "statusName": "编辑中",
    "categoryEnum": "STOCK_SUPPLY",
    "draftTime": "2026-07-23T10:30:00"
  }
}
```

### 4.2 保存单据

| 项 | 内容 |
| --- | --- |
| 接口名称 | 保存单据 |
| 请求方式 | `POST` |
| 请求路径 | `/api/j7/stocktake/save` |
| 请求参数 | `StocktakeSaveDTO` |
| 返回对象 | `JsonVO<StocktakeSaveResultVO>` |

请求示例：

```json
{
  "busNo": "",
  "purposeLocationId": "1001",
  "practitionerId": "2001",
  "categoryEnum": "STOCK_SUPPLY",
  "remark": "期末库存盘点",
  "lines": [
    {
      "itemTable": "med_medication_definition",
      "itemId": "3001",
      "unitCode": "tablet",
      "actualQuantity": 95,
      "profitLossQuantity": -5,
      "actualAmount": 190.00,
      "profitLossAmount": -10.00,
      "inventoryItemId": "4001",
      "lotNumber": "BATCH-20260723",
      "price": 2.00,
      "remark": "期末盘点"
    }
  ]
}
```

响应示例：

```json
{
  "code": 10000,
  "message": "成功",
  "data": {
    "busNo": "PD202607230001",
    "saveMode": "CREATE",
    "statusEnum": "PENDING_APPROVAL",
    "statusName": "待审批",
    "success": true
  }
}
```

说明：

```text
busNo 为空：新增保存，后端生成业务单号。
busNo 不为空：编辑保存，后端按该单号更新盘点明细。
```

### 4.3 保存并提交审批

| 项 | 内容 |
| --- | --- |
| 接口名称 | 保存并提交审批 |
| 请求方式 | `POST` |
| 请求路径 | `/api/j7/stocktake/save-and-submit` |
| 请求参数 | `StocktakeSaveDTO` |
| 返回对象 | `JsonVO<StocktakeSubmitResultVO>` |

请求示例：

```json
{
  "busNo": "PD202607230001",
  "purposeLocationId": "1001",
  "practitionerId": "2001",
  "categoryEnum": "STOCK_SUPPLY",
  "remark": "复核完成，提交审批",
  "lines": [
    {
      "itemTable": "med_medication_definition",
      "itemId": "3001",
      "unitCode": "tablet",
      "actualQuantity": 100,
      "profitLossQuantity": 0,
      "actualAmount": 200.00,
      "profitLossAmount": 0.00,
      "inventoryItemId": "4001",
      "lotNumber": "BATCH-20260723",
      "price": 2.00,
      "remark": "复核无差异"
    }
  ]
}
```

响应示例：

```json
{
  "code": 10000,
  "message": "成功",
  "data": {
    "busNo": "PD202607230001",
    "saveMode": "UPDATE",
    "statusEnum": "APPROVAL",
    "statusName": "审批中",
    "success": true
  }
}
```

## 5. 前端交互流程

```text
点击新增单据
-> 调用 /api/j7/stocktake/draft 获取草稿默认值
-> 用户选择盘点库房并录入明细
-> 点击保存单据
   -> 调用 /api/j7/stocktake/save
   -> 保存成功后刷新左侧列表和右侧详情
-> 点击保存并提交审批
   -> 调用 /api/j7/stocktake/save-and-submit
   -> 保存成功后状态进入审批中
```

## 6. 校验规则

| 校验项 | 规则 |
| --- | --- |
| 盘点位置 | `purposeLocationId` 必填 |
| 经手人 | `practitionerId` 必填 |
| 明细行 | `lines` 不能为空 |
| 物品 | `itemTable`、`itemId` 必填 |
| 单位 | `unitCode` 必填 |
| 实盘数量 | `actualQuantity` 必填且不能为负 |
| 盈亏数量 | `profitLossQuantity` 必填，可正可负可为 0 |
