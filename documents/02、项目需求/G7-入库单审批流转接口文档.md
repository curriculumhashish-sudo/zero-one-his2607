# G7 入库单审批流转接口文档

> 开发人员：lvv
>
> 服务模块：`his-j7-pharmacy`
> Swagger 分组：`G7 入库单审批流转`

## 1. 通用约定

- 基础路径：`/j7/inbound-approval`
- 请求方法：`POST`
- 请求格式：`application/json`
- 调用要求：携带有效 `Authorization: Bearer <token>`，或经网关转发登录用户信息。
- 业务类型兼容：`CABINET_INBOUND_RECEIPT`、`PHARMACY_STOCK_IN`、`INVENTORY_IN`
- 仅允许流转处于 `APPROVAL`（审批中，提交后的标准状态）或 `PENDING_APPROVAL`（待审批，兼容存量数据）状态的入库单。
- 同一 `bus_no` 下的全部药品明细会在同一事务中批量更新。

### 状态流转

| 操作 | 原状态 | 目标状态 |
| --- | --- | --- |
| 撤回 | `APPROVAL` / `PENDING_APPROVAL` | `WITHDRAW` |
| 审批通过 | `APPROVAL` / `PENDING_APPROVAL` | `AGREE` |
| 驳回 | `APPROVAL` / `PENDING_APPROVAL` | `REJECT` |

入库单整体状态机：`DRAFT`（编辑中）→ 保存 → `PENDING_APPROVAL`（待审批）→ 提交 → `APPROVAL`（审批中）→ 审批通过 `AGREE` / 驳回 `REJECT` / 撤回 `WITHDRAW`。
状态值与数据库字段 `wkf_supply_request.status_enum` 指定的 `SupplyStatus#getCode()` 保持一致。

## 2. 请求与响应对象

### 请求体

```json
{
  "busNo": "CIR2026-06-300001",
  "remark": "数量核对无误"
}
```

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `busNo` | String | 是 | 非空，最长 64 字符 | 入库单业务单号 |
| `remark` | String | 条件必填 | 最长 500 字符 | 撤回、驳回时必填；通过时可选 |

### 成功响应

```json
{
  "code": 10000,
  "message": "操作成功",
  "data": {
    "busNo": "CIR2026-06-300001",
    "status": "APPROVED",
    "message": "审批通过"
  }
}
```

### 失败响应

业务校验失败时 `code` 为 `9999`，参数校验失败时 `code` 为 `9995`。

```json
{
  "code": 9999,
  "message": "入库单不在待审批状态，当前状态：APPROVED",
  "data": null
}
```

## 3. 撤回审批

- 路径：`POST /j7/inbound-approval/withdraw`
- 权限：仅入库单原申请人可撤回。
- `remark`：必填，填写撤回原因。

```json
{
  "busNo": "CIR2026-06-300001",
  "remark": "入库数量填写有误"
}
```

成功后返回状态 `WITHDRAWN`。

## 4. 审批通过

- 路径：`POST /j7/inbound-approval/approve`
- 权限：必须为已登录审批操作人。
- `remark`：可选。

```json
{
  "busNo": "CIR2026-06-300001",
  "remark": "数量核对无误"
}
```

成功后返回状态 `APPROVED`，并记录审批人和审批时间。

## 5. 驳回审批

- 路径：`POST /j7/inbound-approval/reject`
- 权限：必须为已登录审批操作人。
- `remark`：必填，填写驳回原因。

```json
{
  "busNo": "CIR2026-06-300001",
  "remark": "药品数量与单据不一致"
}
```

成功后返回状态 `REJECTED`，并记录审批人和审批时间。

## 6. 主要业务错误

| 场景 | 返回消息示例 |
| --- | --- |
| 未登录 | `未获取到当前登录用户，无法执行审批流转` |
| 单据不存在 | `入库单不存在：CIR2026-06-300001` |
| 状态不允许 | `入库单不在待审批状态，当前状态：APPROVED` |
| 非申请人撤回 | `只能由申请人撤回该入库单：CIR2026-06-300001` |
| 撤回原因为空 | `撤回原因不能为空` |
| 驳回原因为空 | `驳回原因不能为空` |
| 并发流转冲突 | `审批流转失败，单据可能已被其他操作处理：CIR2026-06-300001` |

## 7. Swagger 查看方式

启动 `his-j7-pharmacy` 服务后，从启动日志或 Nacos 配置 `sp.j7-pharmacy`
确认实际端口，然后访问：

```text
http://localhost:<实际端口>/j7-pharmacy/swagger-ui.html
```

例如服务启动日志显示端口为 `8087`，则访问：

```text
http://localhost:8087/j7-pharmacy/swagger-ui.html
```

如果页面无法打开，先确认 `his-j7-pharmacy` 已启动、对应端口正在监听，
并确认本地 Nacos `127.0.0.1:8848` 可访问。

在 `G7 入库单审批流转` 分组下检查以上 3 个接口。
