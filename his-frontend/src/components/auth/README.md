# `SigninCallback` 登录回调组件

`SigninCallback` 是一个专门用于处理 `OAuth2` 或 `OIDC` 登录流程中“授权回调”阶段的组件。它负责接收授权服务器返回的代码、处理登录逻辑，并在等待期间向用户展示具有科技感的加载动画。

## 1 功能特性

- **自动处理回调**: 组件挂载（`onMounted`）后立即调用 `auth-manager` 的 `loginCallback()` 方法完成认证。
- **科技感加载动画**: 
  - **行星轨道加载器**: 一个精致的 `CSS` 动画，包含中心行星（`planet-core`）和绕行卫星（`orbit-satellite`）。
  - **动态文案**: 显示“正在安全登录”并伴有循环闪烁的省略号动画。
- **错误处理**: 
  - 登录成功：自动跳转至系统首页 `/home`。
  - 登录失败：调用 `logout()` 清理状态，输出错误信息，并**自动跳转至登录页 **。
- **全屏覆盖**: 使用 `fixed` 定位和高层级（`z-index: 9999`），确保在回调过程中用户无法进行其他操作。

## 2 工作流程

1. **路由触发**: 用户在第三方平台授权后，重定向回本系统的回调地址（通常映射到此组件）。
2. **认证执行**: 
   - 调用 `useAuthManager().loginCallback()`。
   - 该过程通常涉及与后端交换Token、存储用户信息等异步操作。
3. **状态跳转**:
   - 成功 -> `router.push('/home')`。
   - 失败 -> 清理凭证并**重定向至登录页 **。

## 3 样式说明

- **背景渐变**: 使用了柔和的线性渐变 `linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%)`。
- **核心配色**: 采用品牌蓝色系（`#4facfe` 到 `#0072ff`），与整体系统风格保持一致。
- **动画实现**: 
  - `rotate`: 控制轨道旋转。
  - `blink`: 控制文字省略号闪烁。

## 4 使用注意事项

1. **路由配置**: 必须在路由配置文件中为该组件分配一个特定的路径（如 `/callback`）。
2. **依赖插件**: 强依赖于 `@/plugins/auth-manager` 插件，确保该插件已正确初始化。
3. **单次使用**: 该组件仅作为中间过渡页，不应作为常驻页面存在。
