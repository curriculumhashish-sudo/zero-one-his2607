# ErrorBoundary 错误边界组件

`ErrorBoundary` 是一个用于捕获子组件运行时错误并展示降级 UI 的包装组件。它能够防止单个组件的崩溃导致整个应用或大面积页面“白屏”，提升系统的鲁棒性。

## 1 功能特性

- **错误捕获**: 利用 Vue 3 的 `onErrorCaptured` 生命周期钩子，监听并拦截其所有子组件抛出的未处理异常。
- **降级渲染**: 当错误发生时，自动隐藏报错的子组件内容，转而展示一个友好的错误提示界面。
- **防止传播**: 默认返回 `false` 阻止错误继续向父级传播，将错误控制在最小范围内。
- **故障恢复**: 提供“尝试重试”按钮，点击后会重置错误状态并刷新页面，尝试恢复正常运行。

## 2 使用方法

通常建议在应用的最顶层（如 `App.vue`）或大型业务模块的入口处使用该组件。

### 2.1 全局包装 (App.vue)

```html
<script setup lang="ts">
import ErrorBoundary from '@/components/common/ErrorBoundary.vue'
</script>

<template>
  <ErrorBoundary>
    <router-view />
  </ErrorBoundary>
</template>
```

## 3 工作原理

1. **正常状态**: 组件作为透明容器，直接通过 `<slot />` 渲染子内容。
2. **异常触发**: 当后代组件执行报错（如生命周期、渲染逻辑等）时，`onErrorCaptured` 触发。
3. **状态切换**: 组件内部的 `error` 响应式变量被赋值，触发模板切换，展示错误提示 UI。
4. **日志记录**: 错误信息会同步输出到浏览器控制台，方便开发人员排查。

## 4 样式定制

- **居中布局**: 采用 Flexbox 实现错误提示信息的水平垂直居中。
- **视觉反馈**: 使用了 Element Plus 的危险色（`#f56c6c`）标注标题，确保用户能清晰感知到异常状态。

## 5 注意事项

1. **捕获范围**: 错误边界**无法**捕获以下场景的错误：
   - 异步回调（如 `setTimeout`、`Promise.then`）中的错误（除非这些错误被重新抛出到 Vue 生命周期内）。
   - 原生事件处理器中的错误。
   - 服务端渲染（SSR）过程中的错误。
2. **性能影响**: 该组件几乎没有性能开销，建议在核心业务节点大胆使用。
