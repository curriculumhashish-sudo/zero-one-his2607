## 获取单据列表


**接口地址**:`/j7-pharmacy/j7/inbound-approval/list`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`application/json`


**接口描述**:<p>根据条件分页查询药房入库单列表</p>



**请求示例**:


```javascript
{
  "pageIndex": 1,
  "pageSize": 10,
  "busNo": "PSI2026-06-300001",
  "sourceLocationId": "WH_WEST",
  "purposeLocationId": "WH_OUTPATIENT",
  "statusEnum": "APPROVED",
  "startTime": "",
  "endTime": ""
}
```


**请求参数**:


**请求参数**:


| 参数名称                      | 参数说明                                                 | 请求类型 | 是否必须 | 数据类型             | schema               |
| ----------------------------- | -------------------------------------------------------- | -------- | -------- | -------------------- | -------------------- |
| purchaseInboundQuery          | 入库单查询对象                                           | body     | true     | PurchaseInboundQuery | PurchaseInboundQuery |
| &emsp;&emsp;pageIndex         | 查询页码                                                 |          | false    | integer(int64)       |                      |
| &emsp;&emsp;pageSize          | 查询条数                                                 |          | false    | integer(int64)       |                      |
| &emsp;&emsp;busNo             | 单据编号检索 (对应 wkf_supply_request.bus_no)            |          | false    | string               |                      |
| &emsp;&emsp;sourceLocationId  | 来源库房ID (对应 wkf_supply_request.source_location_id)  |          | false    | string               |                      |
| &emsp;&emsp;purposeLocationId | 目的库房ID (对应 wkf_supply_request.purpose_location_id) |          | false    | string               |                      |
| &emsp;&emsp;statusEnum        | 单据状态 (对应 wkf_supply_request.status_enum)           |          | false    | string               |                      |
| &emsp;&emsp;startTime         | 开始时间 (对应 wkf_supply_request.apply_time)            |          | false    | string(date-time)    |                      |
| &emsp;&emsp;endTime           | 结束时间 (对应 wkf_supply_request.apply_time)            |          | false    | string(date-time)    |                      |


**响应状态**:


| 状态码 | 说明     | schema                    |
| ------ | -------- | ------------------------- |
| 200    | 操作成功 | PurchaseInboundPageJsonVO |


**响应参数**:


| 参数名称                             | 参数说明                                           | 类型                  | schema                |
| ------------------------------------ | -------------------------------------------------- | --------------------- | --------------------- |
| code                                 | 状态码                                             | integer(int32)        | integer(int32)        |
| message                              | 提示消息                                           | string                |                       |
| data                                 |                                                    | PurchaseInboundPageVO | PurchaseInboundPageVO |
| &emsp;&emsp;records                  | 当前页单据列表                                     | array                 | PurchaseInboundListVO |
| &emsp;&emsp;&emsp;&emsp;id           | 主键ID                                             | string                |                       |
| &emsp;&emsp;&emsp;&emsp;busNo        | 单据编号                                           | string                |                       |
| &emsp;&emsp;&emsp;&emsp;statusName   | 单据状态 (中文展示: 同意/待审核)                   | string                |                       |
| &emsp;&emsp;&emsp;&emsp;createByName | 制单人姓名 (对应 wkf_supply_request.created_by)    | string                |                       |
| &emsp;&emsp;&emsp;&emsp;approverName | 审批人姓名 (对应 wkf_supply_request.approver_id)   | string                |                       |
| &emsp;&emsp;&emsp;&emsp;applyTime    | 申请/制单时间 (对应 wkf_supply_request.apply_time) | string(date-time)     |                       |
| &emsp;&emsp;&emsp;&emsp;transferPath | 流转路径描述 (如: 西药库 → 门诊西药房)             | string                |                       |
| &emsp;&emsp;&emsp;&emsp;totalPrice   | 总金额 (对应 wkf_supply_request.total_price)       | number                |                       |
| &emsp;&emsp;total                    | 总条数                                             | integer(int64)        |                       |
| &emsp;&emsp;size                     | 每页条数                                           | integer(int64)        |                       |
| &emsp;&emsp;current                  | 当前页码                                           | integer(int64)        |                       |
| &emsp;&emsp;pages                    | 总页数                                             | integer(int64)        |                       |
