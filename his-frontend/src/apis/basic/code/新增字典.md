## 新增字典


**接口地址**:`/j2-basedata/dictionary/addDictItem`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "codeSystemId": 1,
  "dicName": "入院",
  "dicDescription": "无",
  "dicSort": 1
}
```


**请求参数**:


**请求参数**:


| 参数名称                   | 参数说明                         | 请求类型 | 是否必须 | 数据类型       | schema         |
| -------------------------- | -------------------------------- | -------- | -------- | -------------- | -------------- |
| dictItemAddDTO             | 新增字典编码数据传输对象         | body     | true     | DictItemAddDTO | DictItemAddDTO |
| &emsp;&emsp;codeSystemId   | 代码体系ID                       |          | true     | integer(int64) |                |
| &emsp;&emsp;dicCode        | 字典编码(只读，传参后端自动忽略) |          | false    | string         |                |
| &emsp;&emsp;dicName        | 字典名称                         |          | true     | string         |                |
| &emsp;&emsp;dicDescription | 字典描述                         |          | true     | string         |                |
| &emsp;&emsp;dicSort        | 字典排序                         |          | false    | integer(int32) |                |


**响应状态**:


| 状态码 | 说明 | schema       |
| ------ | ---- | ------------ |
| 200    | OK   | JsonVOString |


**响应参数**:


| 参数名称 | 参数说明 | 类型           | schema         |
| -------- | -------- | -------------- | -------------- |
| code     | 状态码   | integer(int32) | integer(int32) |
| message  | 提示消息 | string         |                |
| data     | 数据对象 | string         |                |


**响应示例**:
```javascript
{
	"code": 10000,
	"message": "提示消息内容",
	"data": ""
}
```
