## 获取字典列表(条件+分页)


**接口地址**:`/j2-basedata/dictionary/queryDictItem`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称       | 参数说明                        | 请求类型 | 是否必须 | 数据类型 | schema |
| -------------- | ------------------------------- | -------- | -------- | -------- | ------ |
| dictCode       | 字典类型编码                    | query    | false    | string   |        |
| dicitemKeyword | 关键词:可以是字典列表名称或代码 | query    | false    | string   |        |
| pageIndex      | 查询页码                        | query    | false    | string   |        |
| pageSize       | 查询条数                        | query    | false    | string   |        |


**响应状态**:


| 状态码 | 说明 | schema                   |
| ------ | ---- | ------------------------ |
| 200    | OK   | JsonVOPageDTODictItemDTO |


**响应参数**:


| 参数名称                               | 参数说明                         | 类型               | schema             |
| -------------------------------------- | -------------------------------- | ------------------ | ------------------ |
| code                                   | 状态码                           | integer(int32)     | integer(int32)     |
| message                                | 提示消息                         | string             |                    |
| data                                   |                                  | PageDTODictItemDTO | PageDTODictItemDTO |
| &emsp;&emsp;pageIndex                  | 当前页码                         | integer(int64)     |                    |
| &emsp;&emsp;pageSize                   | 每页显示最大数据条数             | integer(int64)     |                    |
| &emsp;&emsp;total                      | 总条数                           | integer(int64)     |                    |
| &emsp;&emsp;pages                      | 总页数                           | integer(int64)     |                    |
| &emsp;&emsp;rows                       | 当前页数据列表                   | array              | DictItemDTO        |
| &emsp;&emsp;&emsp;&emsp;codeSystemId   | 代码体系ID                       | integer(int64)     |                    |
| &emsp;&emsp;&emsp;&emsp;dicCode        | 字典编码(只读，传参后端自动忽略) | string             |                    |
| &emsp;&emsp;&emsp;&emsp;dicName        | 字典名称                         | string             |                    |
| &emsp;&emsp;&emsp;&emsp;dicDescription | 字典描述                         | string             |                    |
| &emsp;&emsp;&emsp;&emsp;dicSort        | 字典排序                         | integer(int32)     |                    |
| &emsp;&emsp;&emsp;&emsp;dicId          | 字典序号                         | string             |                    |


**响应示例**:
```javascript
{
	"code": 10000,
	"message": "提示消息内容",
	"data": {
		"pageIndex": 1,
		"pageSize": 10,
		"total": 100000,
		"pages": 100,
		"rows": [
			{
				"codeSystemId": 1,
				"dicName": "入院",
				"dicDescription": "无",
				"dicSort": 1,
				"dicId": "1"
			}
		]
	}
}
```
