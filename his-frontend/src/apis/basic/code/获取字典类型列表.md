## 获取字典类型列表（条件+分页）


**接口地址**:`/j2-basedata/dictionarytype/queryall`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称    | 参数说明                          | 请求类型 | 是否必须 | 数据类型 | schema |
| ----------- | --------------------------------- | -------- | -------- | -------- | ------ |
| dictKeyword | 关键字，可匹配字典类型名称、title | query    | false    | string   |        |
| pageIndex   | 查询页码                          | query    | false    | string   |        |
| pageSize    | 查询条数                          | query    | false    | string   |        |


**响应状态**:


| 状态码 | 说明 | schema                         |
| ------ | ---- | ------------------------------ |
| 200    | OK   | JsonVOPageDTODictionaryTypeDTO |


**响应参数**:


| 参数名称                             | 参数说明             | 类型                     | schema                   |
| ------------------------------------ | -------------------- | ------------------------ | ------------------------ |
| code                                 | 状态码               | integer(int32)           | integer(int32)           |
| message                              | 提示消息             | string                   |                          |
| data                                 |                      | PageDTODictionaryTypeDTO | PageDTODictionaryTypeDTO |
| &emsp;&emsp;pageIndex                | 当前页码             | integer(int64)           |                          |
| &emsp;&emsp;pageSize                 | 每页显示最大数据条数 | integer(int64)           |                          |
| &emsp;&emsp;total                    | 总条数               | integer(int64)           |                          |
| &emsp;&emsp;pages                    | 总页数               | integer(int64)           |                          |
| &emsp;&emsp;rows                     | 当前页数据列表       | array                    | DictionaryTypeDTO        |
| &emsp;&emsp;&emsp;&emsp;dictTypeId   | 字典类型ID           | string                   |                          |
| &emsp;&emsp;&emsp;&emsp;dictTypeName | 字典类型名称         | string                   |                          |
| &emsp;&emsp;&emsp;&emsp;dictTypeCode | 字典类型标题         | string                   |                          |


**响应示例**:
```javascript
{
	"code": 10000,
	"message": "提示消息内容",
	"data": {
		"pageIndex": 1,
		"pageSize": 10,
		"total": 100000,
		"pages": 100,
		"rows": [
			{
				"dictTypeId": "1",
				"dictTypeName": "体温单特殊事件",
				"dictTypeCode": "special_event_code"
			}
		]
	}
}
```
