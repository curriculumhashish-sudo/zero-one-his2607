## 创建枚举类型


**接口地址**:`/j2-basedata/sys/add-enum-type`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>租户等信息由jwt等提供，id自动生成</p>



**请求示例**:


```javascript
{
  "enumTypeKey": "enumTypeKey",
  "displayName": "enumTypeName",
  "description": "enumTypeDescription",
  "isSystem": false,
  "status": 0
}
```


**请求参数**:


**请求参数**:


| 参数名称                | 参数说明                       | 请求类型 | 是否必须 | 数据类型       | schema         |
| ----------------------- | ------------------------------ | -------- | -------- | -------------- | -------------- |
| enumTypeAddDTO          | 枚举类型添加DTO                | body     | true     | EnumTypeAddDTO | EnumTypeAddDTO |
| &emsp;&emsp;enumTypeKey | 枚举类型键，必须唯一           |          | true     | string         |                |
| &emsp;&emsp;displayName | 枚举类型名称                   |          | true     | string         |                |
| &emsp;&emsp;description | 枚举类型描述                   |          | false    | string         |                |
| &emsp;&emsp;isSystem    | 是否系统枚举类型               |          | true     | boolean        |                |
| &emsp;&emsp;status      | 枚举类型状态(0-激活, 1-未激活) |          | true     | integer(int32) |                |


**响应状态**:


| 状态码 | 说明 | schema       |
| ------ | ---- | ------------ |
| 200    | OK   | JsonVOString |


**响应参数**:


| 参数名称 | 参数说明 | 类型           | schema         |
| -------- | -------- | -------------- | -------------- |
| code     | 状态码   | integer(int32) | integer(int32) |
| message  | 提示消息 | string         |                |
| data     | 数据对象 | string         |                |


**响应示例**:
```javascript
{
	"code": 10000,
	"message": "提示消息内容",
	"data": ""
}
```
