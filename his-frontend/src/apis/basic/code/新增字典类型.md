## 新增字典类型


**接口地址**:`/j2-basedata/dictionarytype/addConcept`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "name": "gram",
  "title": "克",
  "description": "质量单位：克"
}
```


**请求参数**:


**请求参数**:


| 参数名称                | 参数说明                            | 请求类型 | 是否必须 | 数据类型                | schema                  |
| ----------------------- | ----------------------------------- | -------- | -------- | ----------------------- | ----------------------- |
| dictionaryTypeCreateDTO | 新增编码类型请求参数                | body     | true     | DictionaryTypeCreateDTO | DictionaryTypeCreateDTO |
| &emsp;&emsp;name        | 编码类型编码（英文/拼音，唯一标识） |          | true     | string                  |                         |
| &emsp;&emsp;title       | 编码类型名称（中文显示名）          |          | true     | string                  |                         |
| &emsp;&emsp;description | 编码类型描述（可选）                |          | false    | string                  |                         |


**响应状态**:


| 状态码 | 说明 | schema       |
| ------ | ---- | ------------ |
| 200    | OK   | JsonVOString |


**响应参数**:


| 参数名称 | 参数说明 | 类型           | schema         |
| -------- | -------- | -------------- | -------------- |
| code     | 状态码   | integer(int32) | integer(int32) |
| message  | 提示消息 | string         |                |
| data     | 数据对象 | string         |                |


**响应示例**:
```javascript
{
	"code": 10000,
	"message": "提示消息内容",
	"data": ""
}
```
