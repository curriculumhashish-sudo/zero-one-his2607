# 数据统计

地址：`/report/data-statistics`。

页面统一展示三个功能：患者疾病类型分布、物资入库与出库金额对比、库存物资有效期预警分布。各类日/月流量及接诊趋势不在 J8、J6、C1 页面展示，也不发起对应接口请求。

三个接口均从 `src/apis/report/data-statistics/index.ts` 调用，页面不导入 `mock.ts`。筛选条件统一为 `dateFrom`、`dateTo`、`granularity`、`organizationId`；每个统计卡片独立处理加载、空数据、错误和重试，切换筛选条件会取消旧请求并以请求序号保护新结果。

页面在桌面端按三列排列统计区域；图表点击数据项后展示当前日期、统计粒度、科室和数据项摘要，不增加明细接口。每个失败区域可单独重试，重试结果同样受筛选快照和请求序号保护。

参考原型没有完整的数据统计页面和 DTO；因此本页不宣称统计返回字段来自原型，后端接入时只替换 API 层实现。
