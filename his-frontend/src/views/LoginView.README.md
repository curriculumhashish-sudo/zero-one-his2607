# 登录系统

页面入口：`src/views/LoginView.vue`。登录路由继续由 `src/router/login/index.ts` 管理，正式地址为 `/login`，并保留 `/` 别名；没有重复创建第二条登录路由。

页面依次执行账号登录、租户选择、医院选择、医生机构（科室）选择，最后加载当前用户菜单和当前用户信息。开发环境可以动态开关验证码；生产环境默认启用验证码。每一步失败时保留前一步已经完成的上下文，提交期间禁用重复操作。

Token、租户、医院和科室上下文由 `src/stores/user.ts` 保存；刷新页面后路由守卫重新加载当前用户和菜单时，同时恢复已选择的登录上下文。退出登录会调用退出接口并清理令牌、上下文、菜单和标签页。

API 只从 `src/apis/login/index.ts` 调用，固定包含思维导图“登录系统（12）”对应的 12 个函数：验证码获取/验证、账号登录、租户加载/选择、医院加载/选择、机构加载/选择、当前菜单、当前用户和退出登录。

登录、租户、医院、机构、当前用户和当前菜单 DTO 采用参考原型字段。`src/stores/user.ts` 仅在内部为既有页面补充 `id = userId` 显示兼容，不改变 `loadCurrentUser()` 的原型输出字段。
