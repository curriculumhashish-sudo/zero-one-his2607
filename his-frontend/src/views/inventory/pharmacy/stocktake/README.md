#### 2.添加页面状态

将页面状态改为：编辑中、待审核、审核中、已撤回、同意、驳回，部分按钮或检索区是否可操作由页面状态决定：

- 编辑中：左侧“新增盘点单”按钮不可用，右侧“添加行”、“删除行”按钮、检索区均可用，右侧底部仅“保存单据”、“保存并提交审批”、“删除单据”按钮可用
- 待审核：左侧“新增盘点单”按钮可用，右侧“添加行”、“删除行”按钮、检索区均可用，右侧底部仅“保存单据”、“保存并提交审批”、“删除单据”、“提交审批”按钮可用
- 审核中：左侧“新增盘点单”按钮可用，右侧“添加行”、“删除行”按钮、检索区均不可用，右侧底部仅“撤回”、“审批”、”驳回“按钮可用
- 已撤回：左侧“新增盘点单”按钮可用，右侧“添加行”、“删除行”按钮、检索区均不可用，右侧底部仅“提交审批“按钮可用
- 驳回/同意：左侧“新增盘点单”按钮可用，右侧“添加行”、“删除行”按钮、检索区、右侧底部所有按钮均不可用

#### 3.添加审批流逻辑

通过点击对应底部按钮切换页面状态：

- 编辑中（点击”保存单据“，变为待审核）、（点击”保存并提交审批“，变为审核中）
- 待审核（点击”删除单据“，当前队列卡片删除）、（点击”提交审批“，变为审核中）
- 审核中（点击”撤回“，变为已撤回）、（点击”审批“，变为同意）、（点击”驳回“，在弹窗中输入驳回原因后，变为驳回）
- 已撤回（点击”提交单据“，变为审核中）

注意：左侧卡片状态随着对应审批操作变化而变化

#### 4.添加其他逻辑

点击左侧队列卡片区的“新增单据”或“新增盘点单”的按钮时，均可触发新增事件（在队列卡片区中添加一个卡片，卡片中所渲染的数据为空或默认值，右侧状态改为“编辑中”，并且表单内容同时置为空）

点击添加行时，右侧表单添加一行表单项，所有数据为默认值，点击项目名称后可在弹窗中选择数据进行填充

点击”保存单据“按钮时，如果表单为空，用 `Element Plus` 的消息提示组件提醒：”请至少添加一行盘点明细“，如果表单中存在未选择项目的表单项则提醒：”第x行请选择项目“（x为首个未选择项目的序号），否则保存对应数据并关联至当前卡片

点击左侧队列中的某个卡片时，右侧检索区能显示对应数据，且表单渲染其对应的表单数据
