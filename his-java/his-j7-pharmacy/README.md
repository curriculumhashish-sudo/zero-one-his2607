# his-j7-pharmacy

J7 药房管理模块，基于 Spring Cloud 微服务架构的 business 类型模块。

## 模块信息

- **模块名称**：his-j7-pharmacy
- **基础包名**：com.zeroone.star.j7.pharmacy
- **主启动类**：com.zeroone.star.j7.pharmacy.J7PharmacyApplication
- **上下文路径**：/j7-pharmacy
- **服务端口**：10100

## 技术栈

- Spring Boot 3
- Spring Cloud Alibaba（Nacos 注册中心 & 配置中心）
- MyBatis-Plus
- Druid 连接池
- MySQL
- MapStruct
- Docker
