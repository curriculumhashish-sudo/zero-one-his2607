# 工程简介

药库管理模块，用于处理库存明细、药库进货单、药库出库单、药库盘点单等药库相关业务。

## 主启动类

com.zeroone.star.pharmacy.PharmacyApplication

# 药库管理模块功能清单（总计33项功能）
## 一、库存明细（3项）
1. 获取库存明细列表（条件+分页）
2. 停供/取消停供
3. 导出数据

## 二、药库进货单（10项）
1. 获取单据列表（条件+分页）
2. 获取单据详情
3. 新增单据
4. 保存单据
5. 保存并提交审批
6. 提交审批
7. 撤回审批
8. 审批通过
9. 驳回审批
10. 删除单据

## 三、药库出库单（10项）

8. 审批通过
