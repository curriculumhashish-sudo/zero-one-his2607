# 费用性质管理模块 (his-j3-fee)

**模块名称：** 费用性质管理
**负责人员：** 夏饿、白文儿
**主启动类：** `com.zeroone.star.j3.fee.FeeApplication`
**端口变量：** `sp.fee`
**服务名变量：** `sn.fee`
**上下文路径：** `/fee`

## 业务说明

费用性质用于门诊挂号、住院登记中的费用类型选择，如自费、医保、公费等。需要分析它对后续收费结算的影响。

## 接口清单

| 序号 | 接口功能 | 请求方式 | 建议路径 |
|------|----------|----------|----------|
| 1 | 获取费用性质名称 | GET | `/fee/options` |
| 2 | 获取费用性质列表（条件+分页） | GET | `/fee/page` |
| 3 | 添加费用性质 | POST | `/fee` |
| 4 | 修改费用性质 | PUT | `/fee/{id}` |
| 5 | 删除费用性质 | DELETE | `/fee/{id}` |
| 6 | 停/启用费用性质 | PUT | `/fee/status` |
